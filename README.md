This code simulates an LIF neuron 

1. the parameters set for this scenario are
time constant : 20ms
RMP : -70 mV
threshold potential : -55mV
refractory period : 2ms
noise strength : 1 mV
simulation duration : 500ms

2. the simulation function has 3 components 
1. refractory period checker
2. euler function integration
3. threshold voltage checker


3. it gives out three diagrams
1. neuron under subthreshold suprathreshold and very strong drive of voltage
2. leakiness test
3. Frequency vs input graph

inter spike interval and variation coefficient is printed at the end aswell
